# 广告调整规则与口径

## 1. 口径

- 到手价毛利率 = 履约毛利 ÷ 成交金额（全量订单，30 天）。
- 保本投产比 = 0.7 ÷ 到手价毛利率。0.7 是广告消耗七折口径；如果报表已经折后，不要重复打折。
- 目标投产比 = 保本 × 1.2，平台上限 10，向下取 0.5 的整数倍。
- 投后毛利 = 履约毛利 − 0.7 × 广告消耗；投后毛利率 = 投后毛利 ÷ 成交金额。
- 广告消耗字段带 _discount 的是折前，不是折后。

## 2. 分桶

| 组 | 条件 | 动作 |
|---|---|---|
| 降目标 | 目标 > 保本×1.2，订单≥5 | 降到保本×1.2 |
| 升目标 | 目标 < 保本×1.2，订单≥5 | 升到保本×1.2 |
| 暂停 | 毛利率≤0，或保本×1.2>10 | 暂停 |
| 样本不足 | 订单<5 | 只记录 |
| 维持 | 目标已在保本×1.2 附近 | 不动 |

## 3. 拉黑

- 30 天投后毛利 < 0 且花费 ≥ 100 元。
- 投前毛利率 ≤ 0 且花费 ≥ 20 元。
- 单元上限 50 个；接口是全量覆盖，必须 query 现状再并入，不能只传新增。
- 黑名单接口有 1 分钟窗口限流，失败等 65 秒重试。

## 4. 暂停

- 单次 ≤10 个计划。
- 只暂停不删除；删除不可逆，必须人工确认。
- 暂停前确认不是“货本身亏”以外的原因（例如活动锁价、库存不足）。

## 5. 组合红线

- 单日投后毛利 < -1,000 元：全部目标上调 15%，暂停花费前 5 的亏损计划。
- 单周投后毛利 < 基线 90% 或 GMV < 基线 90%：停止放量，回调 10~15%。
- 单计划 30 天累计亏损 > 200 元：暂停。

## 6. 数据源与降级

1. 计划：jzt_swa_ad_all（全站营销）。
2. 毛利：优先 ge_ad_drill；报“关键指标缺失”时改用指标概况 ad_spu / ad_sku；再不行用 EasyBI 1025136。
3. 广告运营页和指标概况口径不同，不要直接对数。
4. 缺失值不补零；平台部分失败要标 partial。

## 7. 常见坑

- 改预算传 0 会报“日预算不得低于100元”，传空字符串才是“不限”。
- 新建计划的 adDto 里 blackSkuList 不生效，建完要单独补黑名单。
- 代投 API 的计划列表可能看不到刚建的计划，要用页面会话查。
- 出价可改次数 5/次/天，改前看“已改价次数”。
- 平台单次改出价最多 20 个计划，超过要分批。
